# Mobile UI notes — V7

The application now uses a mobile-first navigation pattern below 760px:

- fixed bottom navigation
- 4 most-used actions + More
- More opens a bottom sheet for remaining modules
- large touch targets
- 16px form controls to prevent mobile browser zoom
- compact top bar
- single-column cards/forms
- Principal has only Dashboard, Instructor Accounts and Reports

Desktop retains the full tab navigation.
