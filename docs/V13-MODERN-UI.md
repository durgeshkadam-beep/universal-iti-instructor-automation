# V13 Modern Workspace UI

This release changes presentation only; core V12 automation logic remains in place.

## Desktop
- Persistent left workspace sidebar for the large number of instructor modules.
- White sticky utility header with account controls.
- Wider content canvas suitable for large tables and training records.
- Modern cards, inputs, tables and modal surfaces.
- AI Assistant and Syllabus AI retain distinctive priority styling.

## Mobile
- Existing five-item bottom navigation is retained.
- More sheet, cards, inputs and headers use the same V13 visual language.
- Desktop sidebar is disabled below 961px.

## Login
- Desktop split layout introduces the product before authentication.
- Tablet/mobile automatically falls back to a single focused login card.

## Print
- No V13 screen styles apply under print media. Existing Lesson Plan, Demonstration Plan and record printing remain unchanged.
