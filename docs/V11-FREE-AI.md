# V11 Free AI Agent

## Modes
- Gemini API mode: instructor enters a Gemini Developer API key; key lives only in sessionStorage.
- Manual mode: app generates a structured prompt; instructor can use any free chatbot and paste JSON back.

## AI workflows
1. Syllabus file -> text extraction -> AI structured theory/practical/module/hour detection -> editable preview -> instructor applies.
2. Theory topic -> AI Lesson Plan draft -> preview -> Save Draft / Approve & Keep -> full print format.
3. Practical topic -> AI Demonstration Plan draft -> preview -> Save Draft / Approve & Keep -> full print format.

## Safety
Do not send trainee personal data to free AI services. Generated content must be reviewed by the instructor.
