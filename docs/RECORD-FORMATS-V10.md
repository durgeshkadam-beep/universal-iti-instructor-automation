# V10 Print-Ready Record Formats

V10 adds dedicated preview/print templates for the supplied DTPO/DPO record structures.

## Demonstration Plan
The template includes:
- Government of Maharashtra / DVET / ITI header
- Demonstration number
- Instructor name and designation
- Trade
- Class/batch and academic session
- Unit
- Time allotted
- Proposed/conducted date
- Demonstration/topic
- Purpose/objectives
- Tools/equipment/supplies/training aids
- Procedure / key points & safety precautions / spot hints table
- Questions
- Next demonstration
- Instructor, Group Instructor, Vice-Principal/Principal signature blocks

## Lesson Plan
The template includes:
- Header
- Lesson number
- Instructor/trade/class/unit/time/date/topic
- Purpose/objectives
- Materials/equipment/training aids
- Review
- Motivation
- Steps/topics / information points / chalk-board summary & spot hints table
- Questions
- Summary
- Assignment
- Next lesson
- Signature blocks

The structure is based on the user's supplied DPO/DTPO documents. It is not claimed to be a universal official NCVT form.
