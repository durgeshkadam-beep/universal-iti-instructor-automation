# V9 Inspection-Ready Record Map

This application now contains an internal **Inspection File** to help an instructor prepare evidence.

It is deliberately labelled as an internal readiness checklist, not an official DGT/NCVT form.

## Evidence categories

- Teaching & planning: syllabus/module structure, annual/split-up plan, lesson/theory plan, demonstration plan, daily diary/actual teaching, syllabus coverage.
- Trainee records: trainee master, attendance, progress, assignments.
- Practical & assessment: practical work/models, assessment sheets, evaluation records, class tests, remedial support.
- Student development: OJT/industry exposure, projects, activities, achievements, dated photo/video evidence.
- Administrative: instructor profile/credentials, notices, leave/discipline where applicable, generated registers/reports, backup.
- DTP/DTPO evidence: practical work, theory records, software/lab evidence, trainee design/layout work, instructor-developed resources/question bank/materials.

The checklist is based on evidence-oriented DGT material and should be reconciled with the institute/state's latest instructions before an actual inspection.
