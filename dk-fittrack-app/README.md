# DK FitTrack

**Personal fitness tracker for Durgesh Kadam**

Local-first Android fitness tracker with Firebase device-to-device sync.

- Android package: `in.durgeshkadam.fittrack`
- App name: **DK FitTrack**
- Offline-first: diet, workout and progress data stays on-device
- Sync: Email/Password Firebase Auth + Firestore
- Same account on multiple devices = same main fitness record
- Progress photos remain local in this build

The Android app bundles the web app under `android/app/src/main/assets/www/`.
